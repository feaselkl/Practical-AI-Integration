# Changing or Cancelling an Order

## Before it ships

You can change or cancel an order while its status is **Received**. Once the status changes to **Processing**, the order is being picked in the warehouse and can no longer be changed.

To change or cancel, open a ticket with your order number as soon as possible. Most orders move to Processing within one hour during business hours.

## After it ships

Once an order has shipped, we cannot cancel it. You can return the items under the normal returns policy when they arrive.

## Changing the shipping address

We can change the address only before the order ships. After it ships, the carrier may let you redirect the package for a fee, but we cannot do that on your behalf.
