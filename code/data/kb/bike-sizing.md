# Bike Sizing and Size Exchanges

## Choosing a size

| Rider height | Frame size |
|---|---|
| 4'11" to 5'3" | XS |
| 5'3" to 5'7" | S |
| 5'7" to 5'11" | M |
| 5'11" to 6'2" | L |
| 6'2" and up | XL |

If you are between sizes, choose the smaller size for a more upright, maneuverable ride and the larger size for a more stretched-out ride.

## Size exchanges

If the bike doesn't fit, we exchange it for a different size **free of charge** within 45 days of delivery, as long as it has been ridden **fewer than 50 miles**. We ship the new size as soon as the return is scanned by the carrier.
